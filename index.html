    roBrowser stack documentation

    The stack has a Node.js/Vite frontend (robrowser) and an independent Apache/PHP RemoteClient (remote). MariaDB, rAthena login/character/map and wsProxy provide the game services. See the repository README for architecture and local client-file layout.

    Installation versus operation

    Situation Procedure
    New cluster, no K3s or Longhorn Cluster installation
    Cluster exists, Ragnarok stack is new Fresh Ragnarok installation
    Stack already runs under Flux Operations and rollback
    Local Docker/rAthena or Hercules Deployment and configuration

    Do not use infrastructure setup, namespace resets or k8s-all.sh --apply for routine GitOps updates. k8s-all.sh --check is a bootstrap check and rejects active Flux reconcilers; use the read-only checks in the operations guide on an already active cluster.
